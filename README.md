# Awen Codex

**기원의 서 · Awen Codex**

문장을 읽고 단서를 해석해 탐험하고, 재료를 수집·조합하여 사라진 지식과 세계의 기억을 복원하는 판타지 탐험 게임 프로젝트입니다.

## 핵심 플레이 루프

읽기 → 이해 → 추론 → 탐험 → 수집 → 조합 → 발견 → 복원

## 기술 구성

- **JavaScript**: 이동, 조사, 인벤토리, 조합, 전투, UI, 게임 상태
- **Ink / inkjs**: NPC 대화, 책, 이벤트, 스토리 분기
- **JSON**: 장소, 아이템, 레시피, 몬스터 등 콘텐츠 데이터
- **Supabase (추후)**: 세이브 및 여러 기기 간 이어하기

## 현재 개발 단계

현재 목표는 **기본 엔진 v0.1**입니다.

- 장소 이동
- 조사
- 아이템 획득
- 인벤토리

자세한 진행 상황과 다음 작업은 [`PROJECT_STATUS.md`](./PROJECT_STATUS.md)를 기준으로 관리합니다.
